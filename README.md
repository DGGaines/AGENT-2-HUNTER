# AGENT 2 HUNTER

This is **not** the old Agent 2.0.

Paper hunter. If it cannot be sold, it is not a candidate.
LIVE is dead. START arms $20 clips.

House names (BTC ETH XRP XLM HBAR) are satellites. Never seats.
Ticker at the bottom. No scrollbar.

## Run

```
cd $env:USERPROFILE\Desktop
git clone https://github.com/DGGaines/AGENT-2-HUNTER.git
cd AGENT-2-HUNTER
npm install
npm run desk
```

Or unzip, double-click `CLICK ME.bat`.
